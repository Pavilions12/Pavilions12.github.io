初次探索maimai HDD

解包

  1. 下载 .APP 源文件，这里使用来源于SDGB_1.55.01_20260302122354_0.app | 𝙵𝚛𝚊𝚐𝚛𝚊𝚗𝚌𝚎的文件。
  2. 使用 fsdecrypt 解包 .app 文件获得 .vhd 文件。 fsdecrypt.exe SDGB_1.55.01_20260302122354_0.app .vhd 文件生成在 .app 文件目录下。
  3. 从 .vhd 文件中提取出 Package 目录。

修补

  1. 解压 segatools 中的 mai2.zip ，将解压获得的文件复制到 Package\ 目录下。

  2. 将 MelonLoader 解压得到的文件复制到 Package\ 目录下。[1]

  3. 将 AquaMai.toml 复制到 Package\ 目录下。[1:1]

  4. 在 Package\ 目录中创建 Mods 目录。[1:2]

  5. 下载 AquaMai.dll 并将 AquaMai.dll 复制到 Package\Mods\ 目录下。实测若 AquaMai.dll 的版本大于 1.5.19 会崩溃！[1:3]

  6. 在 Package\ 目录中创建 option 、appdata 、amfs 三个新目录。

  7. 将游戏 ICF 文件重命名为 ICF1 复制到 amfs 目录中。（注意版本一致）

  8. 使用下载的 segatools.ini 示例和 launch.bat 示例替换 Package 目录中的同名文件。

  9. 使用 XenonUnpack.exe 脱壳 amdaemon.exe。

  10. 将 odd.sys 和 odd-loader.bat 复制到 Package 目录。

运行

  1. 以管理员权限运行 odd-loader.bat，不要关闭。

  2. 运行 launch-bat。

故障排除

Game processes have terminated

启动后若只有一个命令行窗口并有如上提示，通常是缺少某个文件夹或未正确挂载 odd.sys。请仔细核对上述步骤。

黑屏，是吗？为什么呢？

除了图片中的提示外，出现此种情况也有可能是缺少某个文件或文件夹（如 option\）导致的。请仔细核对上述步骤。

卡第三屏

若卡在第三启动屏（如下图），可以尝试将机台改为标准机台或关闭 店内招募 功能。

按 测试键 通常为数字区7键（Alpha7）进入测试模式，一号键 通常为 W 和小键盘区8键（KeyPad8）向上移动选项，四号键 通常为 C 和小键盘区3键（KeyPad3）向下移动选项，服务键 通常为数字区8键（Alpha8）向下移动选项，测试键 确定选项。进入 游戏设置，将 设定群组内的标准机 改为 标准设定机。或将 店内招募设置 改为 OFF。

segatools.ini 和 AquaMai.toml 均可配置键盘映射，后者优先级更高。

灰网

通常表现为在第二屏或网络测试中显示 标题服务器 坏 或灰色网络标识。

尽管影响因素众多，但在本示例中，这是配置文件 AquaMai.ini 中配置项 [GameSystem.RemoveEncryption] 未禁用导致的。在此行下方新增一行 Disabled = true 即可解决。

无声音
